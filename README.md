# nofuturekid.github.io

Redirects only. TasmoFleet moved to the `hellwand` organization on 2026-11-06, and GitHub does not
redirect project Pages after a transfer. This user site catches the old URLs:

- `/tasmofleet/` (the old demo root) -> `https://hellwand.github.io/tasmofleet/demo/`
- `/tasmofleet/<path>` (old demo pages, via `404.html`) -> `https://hellwand.github.io/tasmofleet/demo/<path>`

Other projects with their own Pages (for example `/nova/`) are served by their repositories and are not affected.
